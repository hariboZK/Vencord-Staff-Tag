=========================================
        DISCORD STAFF TAG INSTALLER
=========================================

Hello!
This installer will add a special plugin to your Discord that automatically displays 'Staff', 'Admin', or 'Mod' tags next to the names of server moderators.

INSTALLATION STEPS:
1. Double-click the 'AutoInstall.bat' file.
2. Wait for the black screen to finish (takes 1-2 seconds).
3. Discord will close and restart automatically.
4. When Discord opens, go to User Settings -> Plugins.
5. Search for 'StaffTags' and enable the plugin.

That's it! Enjoy!
